2. **Pergunta de NPS:** Sempre inclui "De 1 a 5" na mensagem inicial ou follow-up
3. **Follow-up de Feedback:** Após receber a nota, pergunta "O que achou positivo/poderia melhorar?"
4. **Encerramento Cordial:** Agradece e se coloca à disposição
5. **Adaptação ao Cliente:** Mais turnos para clientes menos diretos, menos para objetivos
